Before you install

Requirements

  • macOS 13 or later on Apple Silicon
  • A wired network interface for AES67

Known limitations

  • Receiving works. Sending has been tested with one device and one channel.
  • Streams are set up with aes67ctl in Terminal. There is no app yet.

Source, documentation and issues: https://github.com/soundsofthesir/AES67_macos_Driver

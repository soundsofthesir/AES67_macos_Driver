Installed

"AES67 Device" is now in Audio MIDI Setup and in each app's device list.

Set up a stream

In Terminal, check the network interface, then add a stream:

aes67ctl doctor --interface en0
sudo aes67ctl setup --interface en0 --send 239.69.1.1

Replace en0 with your AES67 interface and the address with a free multicast group. aes67ctl help lists every command.

Logs

  • Install: /var/log/aes67driver_install.log
  • Keepalive: /var/log/aes67driver-keepalive.log

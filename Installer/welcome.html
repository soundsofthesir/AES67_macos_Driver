AES67 Driver

Adds "AES67 Device" to Core Audio: 128 inputs and 128 outputs carried as AES67 streams on the network.

This is an experimental pre-release. It has been tested with only a few devices. Don't rely on it for a live show.

Installs

  • /Library/Audio/Plug-Ins/HAL/AES67Driver.driver
  • /usr/local/bin/aes67ctl
  • The com.aes67driver.keepalive background service, which keeps send streams running while no app plays

Core Audio restarts at the end of the install, which briefly interrupts any app playing or recording sound.
